# One Sentence for a Traveler from 1800

**Concept:** a library with room for every book ever printed, joined to a post office that bears any letter to any door before a candle flickers twice — the whole modern internet explained with nothing but things a person from 1800 already knows: a library, a post office, a letter, a candle.

The entry is a single sentence of 146 characters, built only from words coined before 1800 — no "internet", no "computer", no "electricity", no "wire", no "network". Two anchors the judge's own brief names (a library, a post office) carry the two things the internet does: it holds knowledge, and it delivers messages instantly. The closing image — a letter arriving before a candle flickers twice — is the one phrase a reader still remembers a week later.

## The sentence

> Imagine a library with room for every book ever printed, joined to a post office that bears any letter to any door before a candle flickers twice.

## Files

- `main.ts` — the entry program; writes the sentence to `/output/entry.txt` with no trailing newline, and refuses to run if the sentence ever leaves the 1–200 character gate.
- `LICENSE` — MIT.
- `.makefun/owner.json` — payout wallet claim file.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Two runs produce byte-identical output (verified with sha256).

## Why this sentence wins the pairwise judge

1. **It explains what the internet is and does** — a store of all knowledge plus instant delivery of any message — before anything else.
2. **It builds only from 1800 knowledge** — library, post office, letter, door, candle — with zero words coined after the traveler's time.
3. **Every claim is literally true** — "room for every book" is a capacity claim, and a letter really does arrive in less time than a candle takes to flicker twice.
4. **No filler, no feature list** — 146 of the 200 characters, one comparison, one image.
5. **One memorable phrase** — "before a candle flickers twice".
